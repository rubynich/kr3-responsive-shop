Дата проверки: 01.11.2026.
Инструмент: Lighthouse из Chromium (категории Accessibility, Best Practices, SEO).
Проверялась локальная версия сайта, запущенная через `python -m http.server`.

Скриншот отчёта для главной страницы: `accessibility-report.png`.

## Что проверялось вручную

- переход по странице клавишей `Tab` и видимость фокуса;
- работа ссылки пропуска к основному содержимому;
- открытие и закрытие модального окна с клавиатуры, возврат фокуса на кнопку;
- сообщения об ошибках формы: `role="alert"`, `aria-invalid`, `aria-describedby`;
- контраст текста и фона (все основные пары — не ниже 4.5:1);
- наличие `alt` у изображений и `label` у полей формы;
- один `h1` на страницу и логичный порядок заголовков;
- отсутствие горизонтального скролла на ширинах 360–1440 px.

## Найденные и исправленные проблемы

| Проблема | Исправление |
| --- | --- |
| Не было ссылки пропуска к содержимому | Добавлена `.skip-link` и `id="main"` у `main` |
| Фокус был тонким (2px) и терялся на части элементов | Единый `:focus-visible` с `outline: 3px` для ссылок, кнопок и полей |
| Белый текст на зелёном бейдже давал контраст 4.46:1 | Затемнён `--color-success` до `#0f6b2c` (6.65:1) |
| Повторяющиеся ссылки «Подробнее» и «Оставить заявку» были непонятны вне контекста | Добавлены `aria-label` с названием товара |
| У модального окна не было кнопки закрытия с понятным именем | Добавлена кнопка `×` с `aria-label="Закрыть окно"` |
| Ошибки формы не объявлялись скринридером | У сообщений `role="alert"`, у полей `aria-invalid` и `aria-describedby` |
| Подсказка формата телефона терялась при показе ошибки | `aria-describedby` объединяет подсказку и текст ошибки |
| Ссылки подвала не были размечены как навигация | Добавлен `nav` с `aria-label="Навигация в подвале"` |
